## Notes for the reviewer

- **graduate**: Written as the noun (a person with a degree). The verb (“graduate from university”) is just as common.
- **research**: Written as the noun, which is uncountable (“some research”, not “a research”).
- **exhaust**: Written as the noun (vehicle gas). The verb (“exhaust resources”, “exhausted”) is also useful in Environment essays.
- **greenhouse**: Almost always used in “greenhouse gas” / “greenhouse effect” in IELTS, so the example uses that.
- **fossil fuel**, **resource**: Usually plural (“fossil fuels”, “natural resources”); the examples use the singular so the gap-fill matches exactly.
- **artificial**: The example uses the food sense (“artificial colours”) so it does not overlap with the separate **artificial intelligence** entry.
- **application**: In everyday English “app” is far more common for phone software; the example keeps the full word.
- **faculty**: Two senses (university department; mental ability). The example uses the university sense.
- **dropout**: Most useful as “dropout rate”; the person sense is informal.
